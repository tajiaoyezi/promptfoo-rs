# Code of Conduct

## Our pledge

We want promptfoo-rs to be a practical, respectful, and useful open-source project. Participants are expected to communicate with care, assume good intent where reasonable, and focus on the technical work.

## Expected behavior

- Be respectful of different backgrounds, experience levels, and viewpoints.
- Give constructive feedback that is specific and actionable.
- Keep discussions focused on the issue, pull request, spec, or decision at hand.
- Acknowledge mistakes and correct them.
- Respect privacy and do not publish private information without permission.

## Unacceptable behavior

- Harassment, threats, insults, or personal attacks.
- Sexualized language or attention in project spaces.
- Discriminatory comments or exclusionary conduct.
- Publishing private contact details, credentials, tokens, logs, or private service data.
- Repeated disruption of issue, PR, or discussion threads after maintainers ask for a change in behavior.

## Scope

This code of conduct applies to project spaces, including GitHub issues, pull requests, discussions, reviews, and any public space where someone represents the project.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants when behavior violates this code of conduct. Enforcement should be proportional to the impact and should prioritize the safety and usefulness of the project space.

If the report involves a security vulnerability or private data, use the private process in [SECURITY.md](SECURITY.md) instead of a public issue.
