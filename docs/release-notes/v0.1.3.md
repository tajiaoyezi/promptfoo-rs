# promptfoo-rs v0.1.3

**Release date:** 2026-06-07  
**Channel:** GitHub Releases (v1 authorized channel)  
**Approval references:** `approval:v1-github-releases-only-2026-06-06`, `approval:legal-brand-independent-reimplementation-2026-06-06`

## Positioning

promptfoo-rs is an **independent reimplementation** of promptfoo-style local eval workflows. It is **not** the official promptfoo project and does not imply upstream endorsement.

Product compatibility is **frozen at `promptfoo@0.121.15`** per ADR-012. This release does not track promptfoo npm/HEAD drift.

## What this release adds

- **Phase 49 gate alignment** on the frozen product baseline:
  - `current-upstream-policy.json` defaults to `target_mode=product-baseline` with `product_baseline_frozen=true` and `current_upstream_rebaseline_required=false`
  - Runtime gates consume v1 authority/publication waivers → `required_user_decision_count=0`, `v1_scope_ready=true`
  - `authority-decisions-gate` reports `perfect_refactor_decision_ready=true` when manifest rows are resolved
- **Same GitHub Releases binary matrix** as v0.1.2: Linux x64/arm64, Windows, macOS arm64/x64

## What this release does not claim

- **Not** a perfect-refactor or bug-free completion of promptfoo (`perfect_refactor_claim_allowed=false`)
- **Not** full live-provider, cloud, hosted-server, or account-linked config parity (formal v1 waivers apply)
- **Not** publication on Cargo, npm registry, Docker, Homebrew, or GitHub Marketplace (v1 deferred channels)
- **Not** ongoing alignment with promptfoo releases after `0.121.15`

Allowed quality wording: **no known release-blocking defects under declared gates**.

## Install

Download the archive for your platform from this GitHub Release, verify `SHA256SUMS`, and place `promptfoo` or `promptfoo-rs` on your `PATH`.

Linux x64 example:

```bash
curl -LO https://github.com/tajiaoyezi/promptfoo-rs/releases/download/v0.1.3/promptfoo-rs-0.1.3-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/tajiaoyezi/promptfoo-rs/releases/download/v0.1.3/SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing
tar -xzf promptfoo-rs-0.1.3-x86_64-unknown-linux-gnu.tar.gz
./promptfoo --help
```

See [docs/release.md](../release.md), [docs/decisions/adr-012-product-independence-baseline-freeze.md](../decisions/adr-012-product-independence-baseline-freeze.md), and [docs/compatibility/v1-release-authority-policy.md](../compatibility/v1-release-authority-policy.md) for gate boundaries.
