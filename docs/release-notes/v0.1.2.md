## Install

Download the archive for your platform from this GitHub Release, verify `SHA256SUMS`, and place `promptfoo` or `promptfoo-rs` on your `PATH`.

Linux arm64 example:

```bash
curl -LO https://github.com/tajiaoyezi/promptfoo-rs/releases/download/v0.1.2/promptfoo-rs-0.1.2-aarch64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/tajiaoyezi/promptfoo-rs/releases/download/v0.1.2/SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing
tar -xzf promptfoo-rs-0.1.2-aarch64-unknown-linux-gnu.tar.gz
./promptfoo --help
```

See [docs/release.md](../release.md) and [docs/compatibility/v1-release-authority-policy.md](../compatibility/v1-release-authority-policy.md) for gate boundaries.
