## Positioning

promptfoo-rs is an **independent reimplementation** of promptfoo-style local eval workflows. It is **not** the official promptfoo project and does not imply upstream endorsement.

## What this release provides

- Rust-first CLI binaries: `promptfoo` (drop-in alias) and `promptfoo-rs`
- Local eval, config parsing, result output, compatibility gates, and viewer data contracts covered by S2V verification
- Frozen-baseline compatibility release gate: **stable allowed** for declared local scope

## What this release does not claim

- **Not** a perfect-refactor or bug-free completion of promptfoo current-latest HEAD (`perfect_refactor_claim_allowed=false`)
- **Not** full live-provider, cloud, hosted-server, or account-linked config parity (formal v1 waivers apply)
- **Not** publication on Cargo, npm registry, Docker, Homebrew, or GitHub Marketplace (v1 deferred channels)

Allowed quality wording: **no known release-blocking defects under declared gates**.

## Install

Download the archive for your platform from this GitHub Release, verify `SHA256SUMS`, and place `promptfoo` or `promptfoo-rs` on your `PATH`.

```bash
cargo build --workspace --release   # or use the release archive
./promptfoo --help
```

See [docs/release.md](../release.md) and [docs/compatibility/v1-release-authority-policy.md](../compatibility/v1-release-authority-policy.md) for gate boundaries.
