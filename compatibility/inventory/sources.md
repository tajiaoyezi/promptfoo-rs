# Upstream Inventory Sources

**Status**: Ready
**Basis**: task-11.2, PRD §Compatibility Matrix, ADR-009, docs/audits/promptfoo-upstream-inventory-gap-2026-05-30.md

## Inputs

- Audit command inventory: 52 upstream command patterns and 85 command-related files.
- Audit provider inventory: upstream provider directories and root provider modules.
- Audit assertion inventory: 56 upstream assertion modules.
- Audit redteam inventory: 126 plugin files and 32 strategy files, summarized by category in the audit.
- PRD compatibility matrix: output, config, Node API, viewer, and release surfaces.
- task-11.1 target policy: stable inventory is scoped to the frozen baseline, while moving upstream observations remain tracking evidence.

## Extraction Policy

- Every row in `compatibility/inventory/upstream-items.json` must have `stable_id`, `category`, `name`, `source_reference`, `level_hint`, `status`, and `owner_hint`.
- `stable_id` is generated by `InventoryItem::stable_id(category, name)`.
- `level_hint` must be `P0`, `P1`, or `P2`.
- `status=unresolved` rows are release-blocking until a later task classifies them as native, bridge, unsupported, or later with reason evidence.

## Known Boundaries

- This task creates the machine-readable inventory substrate and seed item-level rows from the audit package.
- Full source-registry expansion for long-tail providers/assertions/redteam plugins continues in task-14.1 and task-14.2.
- Matrix expansion and no-silent-omission enforcement continue in task-11.3.
